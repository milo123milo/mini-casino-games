# 🎰 Mini Casino Games  
### 🎮 Handheld ESP32-S3 Based Console

Welcome to **Mini Casino Games**, a compact and portable gaming console powered by the **ESP32-S3** chip.  
This project is a fusion of retro fun and embedded innovation, perfect for makers, learners, and tinkerers.

---

## 📘 Full Documentation & Replication Guide

To replicate this project, check out the detailed documentation below, including hardware schematics, PCB design, firmware installation, and 3D printable case:

📄 [Notion Documentation](https://sunset-captain-274.notion.site/Replication-Guide-For-Mini-Casino-Games-Handheld-ESP32-S3-Based-Console-1d1d26625977801a877bd9dc9023a142)

---

## ✨ Features

- 🎲 Multiple casino-style mini games built-in  
- 💡 Colorful display with intuitive graphics
- 🔊 Integrated audio output for sound effects and feedback
- 🛠️ Easy to replicate with open-source files  
- 📦 Optional 3D-printed case design  

---

## 💬 Why This Project?

This console was built to explore what’s possible with minimal hardware and maximum creativity.  
It’s not just a toy — it’s an entry point into the world of **hardware prototyping**, **game development**, and **embedded UI design**.
